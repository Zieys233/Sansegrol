# Sansegrol

Sansegrol is a modern desktop browser application based on PySide6, Flask and Rust

# Environment Configuration

Please ensure that you have a local `python 3.8.9` environment on your machine.

Use the following commands to install the dependency libraries:

```
pip install pyside6 -t ./python-3.8.9-embed-amd64/Lib/site-packages
pip install flask -t ./python-3.8.9-embed-amd64/Lib/site-packages
pip install logging -t ./python-3.8.9-embed-amd64/Lib/site-packages
```
